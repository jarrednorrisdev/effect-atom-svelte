# `effect-atom-svelte`

Svelte 5 bindings for the Effect Atom modules (`effect/reactivity`), in the shape of `@effect/atom-react` and `@effect/atom-vue`.

**Status:** pre-release, not published yet. It targets `effect` 4, Svelte 5.57+ with `experimental.async`, and SvelteKit 3.

## Installation

```sh
npm install effect effect-atom-svelte
```
